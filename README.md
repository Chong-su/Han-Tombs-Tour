## 一、项目简介

汉代墓葬被称为保存两汉社会记忆的"地下档案馆"，但大众接触古墓题材大多来自盗墓类文艺作品，墓葬背后的**礼制、文物与生死观念**反而鲜少被看见，甚至常把考古与盗墓混为一谈——**正统的古墓文化一直缺少一个贴近普通人的体验入口**。

《汉冢行》把汉墓还原成一个**值得被阅读的文化空间**：玩家作为意外闯入的普通人，穿行于汉代墓室与守陵村落之间，依靠对历史文化的理解，寻找回归现实的出路。

> 项目名中的"**行**"，既是行走游历，也是亲身践行——一次普通人躬身走近汉代丧葬礼制的体验。

**开发规模**：2 人团队 · 全部玩法环节为自研脚本 · 不依赖玩法中间件

## 二、玩法特色

### 设计理念：以解谜替代战斗，以仪式替代掠夺

全程**没有敌人，也没有攻击打斗系统**。玩家所能做的只有行走、观察、聆听、作答与拼接器物。这不是技术条件的限制，而是题材本身的价值选择——汉代厚葬的内核是对逝者的敬重，若让玩家在古墓中打斗劫掠，便与墓葬承载的敬畏精神相冲突。

### 三组汉代文化元素，构成玩法与叙事骨架

| 文化元素 | 历史依据 | 在游戏中的呈现 |
|---|---|---|
| **玉璧** | 汉代以玉敛葬，玉璧圆以象天，承担祭祀与安魂下葬之功用 | 一块完整玉璧拆为三片，散落墓室、村落、山崖三处；碎片是离开秘境的关键道具，暗含"**碎而复圆**"意象，呼应考古拼接残件、复原历史遗存的过程 |
| **策问应答** | 策问是汉代察举选才的重要形式（汉文帝问晁错、汉武帝问董仲舒） | 第二幕通关方式为守陵老者的**策问对答**，把历史知识化为解谜钥匙 |
| **守陵人** | 汉代帝陵与王侯陵园设有守陵人员，世代居住守护陵寝，形成守陵聚落 | 村庄背靠的石山，实为被草木覆盖两千年的陵寝封土——**山即是冢**；白发老者与村民正是守陵后人 |

### 三幕结构：从"识器"到"明理"再到"归位"

```
第一幕 墓室 —— 识：观察文物形制与纹饰，感受汉代器物工艺美学
第二幕 村落 —— 明：经由策问对答，延伸至丧葬礼制、选官制度与时代风貌
第三幕 山冢 —— 归：在封土完成玉璧拼合，体会"碎而复圆"与慎终追远
```

玩家身份也从外行逐步转变为"半个守陵人"，与考古学从器物、到制度、再到伦理的认知递进同构。

## 四、技术要点

### 4.1 架构三原则

1. **自研静态事件总线（EventCenter）** —— 实现系统间零硬引用解耦，对话、任务、策问、旁白、声音模块互不直接依赖
2. **ScriptableObject 配置化** —— 对话、任务、流程均以配置资产驱动，调整内容无需改动代码
3. **"触发器 → 事件 → 响应"统一抽象** —— 区域探索、对话触发、旁白链、BGM 切换共用同一套模型，**关卡搭建无需编码**

### 4.2 关键技术攻坚

| 问题 | 解决方案 |
|---|---|
| 跨场景引用与 `DontDestroyOnLoad` 限制 | 设计**常驻 Canvas 单例** + **触发器断链架构**，保证对话/任务系统跨场景可用且不产生悬挂引用 |
| 对话自动推进的节奏控制 | "**打字机、配音、停留**"三源节拍协程：兼顾配音不被截断与玩家阅读节奏；支持逐字显形与跳字 |
| 第一人称步态手感 | 头部晃动采用**双波形叠加 + 速度归一化 + 状态幅度倍率**，使不同移动状态下的镜头自然可信 |

### 4.3 渲染与表现

- **氛围即叙事**：体积雾 + 物理天空 + 固定曝光，构成统一的画面语言
- **幕间视频转场**：将章节"幕"化，强化叙事节奏
- **WindControl 风场系统**：驱动 HDRP 植被风动着色，松林、灌木按材质差异化随风摆动，并**联动风声环境音**，让山林"活"而可信

## 六、项目结构

```
汉冢行/
├── Assets/
│   ├── Scripts/            # 自研脚本（14 个功能模块，见上表）
│   ├── Sence/              # 场景：开始场景 / 墓室场景 / 村庄场景
│   ├── mode/               # 角色、道具、文物模型与材质
│   ├── 动画/ 动作/ 动作测试/ # 动画剪辑与 Animator 控制器
│   ├── 陪葬品/              # 汉代文物模型（玉璧、编钟、青铜剑、竹简等）
│   ├── 汉墓FBX/             # 墓室结构模型
│   ├── 天空盒/ 贴图/ 字体/    # 环境与 UI 资源
│   ├── 配音/ 背景音乐/ 音效/   # 音频资源
│   └── Settings/           # HDRP 管线与画质配置
├── ProjectSettings/        # 工程设置
└── Packages/               # 依赖包清单
```

## 七、开发环境与运行

| 项 | 版本 |
|---|---|
| 引擎 | Unity 2023.2.20f1c1（兼容团结引擎同版本） |
| 渲染管线 | HDRP 16.0.6（同时保留 URP / ShaderGraph 依赖） |
| 其他依赖 | UGUI 2.0.0、Timeline 1.8.6、Visual Scripting、2D Sprite |
| 目标平台 | Windows（PC） |

**运行步骤**

1. 用 Unity 2023.2.20f1c1（或同版本团结引擎）打开工程
2. 打开 `Assets/Sence/开始场景.unity`
3. 点击 Play —— 按构建顺序 **开始场景 → 墓室场景 → 村庄场景** 依次体验三幕

## 八、素材说明（重要）

为保证仓库体积可控（完整工程约 **6GB**），本仓库**未包含约 5GB 的第三方素材与高清资源**，`.gitignore` 已排除：

- Unity 官方示例地形素材：`Assets/TerrainSampleAssets/`
- 第三方环境音素材包：`Assets/Audio/`
- 第三方植被 / Quixel / HDRI 素材：`Assets/Art/UnityHDRI/`、`Assets/Art/Environment/_ExternalContent/`、`Assets/Art/Environment/Vegetation/`、`Assets/Foliage Free/`
- 高清贴图与 HDRI：`*.tif` `*.tiff` `*.exr` `*.hdr`
- 幕间视频：`*.mp4` `*.mov`
- 第三方 `.wav` 环境音（自研配音 `Assets/配音/` 与 `Assets/背景音乐/` 已保留）
- Unity 生成物与 IDE 文件：`Library/` `Temp/` `obj/` `Logs/` `UserSettings/` `*.csproj` `*.sln`

> ⚠️ 因此**直接克隆本仓库打开工程时，部分贴图、植被、环境音与视频会缺失（引用为空）**，属预期现象，不影响脚本与架构的阅读。如需完整可运行工程（含素材），请与作者联系。
